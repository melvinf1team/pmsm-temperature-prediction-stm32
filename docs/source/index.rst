STM32 PMSM Datalog Dashboard
============================

Documentation du logiciel Python permettant de contrôler, lire et enregistrer
les données issues d'une carte STM32 B-G473E-ZEST1S connectée à une power board
STDES-LVHP01.

Le dashboard permet :

* la connexion série à la carte STM32 ;
* l'envoi des commandes de configuration moteur ;
* le lancement et l'arrêt du datalogging ;
* l'enregistrement CSV ;
* l'affichage des données en temps réel ;
* la visualisation graphique des variables moteur et température.
